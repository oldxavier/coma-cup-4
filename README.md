# Coma Cup 4 Stats

Standings, records and oddities from every game of [Coma Cup 4](https://liquipedia.net/ageofempires/Coma_Cup/4),
a 4v4 Age of Empires II tournament on Black Forest for the
[Rage Forest community](https://discord.gg/PkvTNwy4vx).

**Site:** https://oldxavier.github.io/coma-cup-4/

Each game's recording is replayed in CaptureAge and logged unit by unit. `site/data/cc4.json` holds
everything the page shows and is regenerated as new series are played; the page itself is plain
HTML, CSS and JavaScript in `site/`.

A sibling of [Rage Forest Ratings](https://oldxavier.github.io/rageforest-ratings/).
